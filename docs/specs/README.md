# Design specs (frozen history)

The original design specs of shipped features, kept because code comments cite them. They are
frozen: they record what was decided at the time and are not updated as the code moves on, so
parts of them no longer match today's behaviour (for example, engine changes now apply live
instead of restarting Wind). The code and [the architecture docs](../architecture/README.md) are
authoritative. New plans and brainstorm output are not committed; open work lives in GitHub issues.
Source paths here (`src/<file>`) predate the src/ regrouping into area folders (#486); find a file's
folder in the source map of [01](../architecture/01-overview.md#source-map).
